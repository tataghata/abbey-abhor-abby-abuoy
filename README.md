## Download and browse

High-resolution originals, native artwork, and PDFs use Git LFS. Install [Git LFS](https://git-lfs.com/), then clone:

```sh
git lfs install
git clone https://github.com/tataghata/abbey-abhor-abby-abuoy.git
cd abbey-abhor-abby-abuoy
git lfs pull
```

Open `word-atlas-111-new/index.html` in a browser for the searchable gallery, shuffle control, and full companion explanations. Open `word-atlas-23.html` for the earlier collection. These galleries run locally without a server.

The latest collection contains 111 unique 80-megapixel PNGs with sRGB color tagging and 400 dpi metadata, plus a 111-page PDF with vector typography and bookmarks. [Validation results](word-atlas-111-new/validation.json) and [file checksums](word-atlas-111-new/file-manifest.json) are included.

Each collection's README describes its source and reproduction workflow. macOS, Swift/AppKit, Python, NumPy, and a C++ compiler are used for the newer renderings.
